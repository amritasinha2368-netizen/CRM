# GOG CRM

A modern CRM dashboard built with React, TypeScript, and Tailwind CSS.

## Features

- Lead management & pipeline tracking
- Student & admissions tracking
- Campaign & follow-up management
- Reports & analytics dashboards
- Role-based views (Admin, Team Leader, Counsellor)

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- Zustand (state management)
- Recharts (charts)
- Radix UI + Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
